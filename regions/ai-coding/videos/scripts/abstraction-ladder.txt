=== title
heading: 抽象的階梯
sub: 每一層都換來表達力；LLM 這一層放棄的是形式化的翻譯保證
> 程式設計的歷史，常被說成一條抽象的階梯，而 AI 輔助程式設計是最新的一階。這個說法沒有錯，但它隱藏了一個對工程決策最重要的區分：每一層換來了什麼，又放棄了什麼。這一章就來把它拆開。

=== bullets
heading: 常見的敘事：一路往上的抽象
- 組合語言，然後是由編譯器翻譯的高階語言
- 程序式、物件導向、腳本語言
- 機器學習框架，以及以大型語言模型為基礎的 AI 輔助
- 一句流行的說法：「英文是最熱門的新程式語言」
> 常見的敘事是這樣的：從機器碼到組合語言，再到由編譯器翻譯的高階語言；然後是程序式、物件導向、腳本語言；再到機器學習框架，最後是以大型語言模型為基礎的 AI 輔助程式設計。
> 每一步都把繁瑣的細節藏到背景。於是有了一句流行的說法：英文是最熱門的新程式語言，用自然語言描述，就能得到程式碼。也常聽到開發者說，AI 已經寫了大部分的程式碼，自己是提示加編輯，而不是手寫。

=== table
heading: 把「抽象」拆成三個可檢驗的性質
| 層 | 翻譯保證 | 可重現 |
| 組譯器 | 一對一對應 | 是 |
| 編譯器與高階語言 | 語言規格 | 是 |
| 函式庫與框架 | API 契約與文件 | 是 |
| LLM 輔助 | 沒有形式化規格 | 多數供應商不保證 |
> 要讓這個敘事對決策有用，至少要分開看三件事：表達力、翻譯保證，以及可重現。表達力是同樣的意圖你要寫多少；翻譯保證是上層的東西如何變成下層的行為，由誰保證語意一致；可重現是同樣的輸入，是否得到同樣的輸出。
> 組譯器是一對一的對應。編譯器有語言規格可以對照，編譯器當然也有錯誤，但那是可以回報、可以修正的系統性錯誤。函式庫有介面契約與文件。到了大型語言模型這一層，沒有形式化的規格，輸出是機率分佈中的一個樣本，多數供應商也不保證可以逐字重現，連溫度設為零也一樣。

=== bullets
heading: 為什麼「英文是新的程式語言」會誤導
- 你的提示詞不是規格：沒有東西能判定輸出是否符合它
- 規格必須是可執行的：測試、型別、契約、範例
- 工作從「寫」轉成「讀、判斷、驗證」，審查成為瓶頸
- 槓桿在讓驗證變便宜，而不是讓生成變快
> 所以「英文是新的程式語言」這個比喻會誤導。編譯器是形式語言到形式語言的函數，有規格可以對照；大型語言模型做的，是從含糊的自然語言，到一個很可能合理的程式。你的提示詞不是規格，因為沒有任何東西能判定輸出是否符合它。
> 這有三個工程後果。第一，規格必須是可執行的：測試、型別、契約、範例。可以這樣看：提示詞只是產生候選解的手段，測試才是驗收標準。第二，工作內容從寫轉成讀、判斷與驗證，審查能力成為瓶頸；就算八成的程式碼是對的，也代表大約每五段就有一段要人修正。第三，最大的槓桿是讓驗證變便宜：快速可靠的測試、型別、風格檢查，以及可重現的開發環境。

=== bullets
heading: GenAI 的版圖
- AI 包含機器學習，機器學習包含深度學習，深度學習包含生成式 AI
- 大型語言模型屬於生成式 AI，常被稱為 foundation model
- 巢狀圖表示類別包含，不是時間先後，也不是能力高低
- foundation model 不等於你用的產品：產品還包含 context 蒐集與前後處理
> 最後補上名詞的版圖。人工智慧包含機器學習，機器學習包含深度學習，深度學習包含生成式 AI，大型語言模型是生成式 AI 的核心，常被稱為基礎模型。
> 有兩個地方容易誤讀。第一，這張巢狀圖表示的是類別包含，不是時間先後，也不是能力高低；大型語言模型是深度學習裡的一種生成式 AI 模型，不是比機器學習更高級的東西。第二，基礎模型不等於你用的產品；產品是模型、context 蒐集、前後處理與介面的總和，比較兩個工具時，差別常在模型以外的部分。

=== quiz
heading: 檢查點
q: 「英文是最新的程式語言」這個比喻，在工程決策上最大的問題是什麼？
- 英文太冗長，寫 prompt 比寫程式慢
- LLM 無法產生需要編譯的語言
- * LLM 的輸出沒有形式化保證，翻譯保證必須由測試、型別、審查來承擔
- LLM 產生的程式碼一律是錯的
> 檢查點：這個比喻在工程決策上最大的問題是什麼？答案是第三個。問題不在表達力，而在保證。你信任編譯器，是因為它有規格、結果可重現；大型語言模型沒有這兩項，所以信任必須來自外加的驗證。說它一律是錯的，或不能產生需要編譯的語言，都是事實錯誤；說它太冗長，則是風格問題，不是決策問題。

=== end
heading: 重點回顧
- 抽象帶來表達力，但每一層的翻譯保證不同
- LLM 這一層沒有形式化規格，也不保證可重現
- 規格要寫成可執行的檢查
- 投資讓驗證變便宜的基礎建設
> 回顧一下。抽象帶來表達力，但每一層的翻譯保證不同；大型語言模型這一層沒有形式化規格，也不保證可重現；所以規格要寫成可執行的檢查，而最值得投資的，是讓驗證變便宜的基礎建設。
> 思考練習會請你向團隊說明，為什麼生成速度不是主要瓶頸，並提出三項讓驗證變便宜的投資。
